# Building Lumen Proxy from source

These steps reproduce the Firefox package submitted to addons.mozilla.org byte for byte.

## Environment

- Any OS supported by Node.js (verified on Ubuntu 24.04, x86-64).
- Node.js 22.19.0 and npm 10.9.3 (any Node.js 20.19+ / 22.x works; these are the versions used for the release).
- Internet access for `npm ci`.

## Build

```bash
npm ci
npm run build:firefox
```

The extension is written to `dist/firefox/`. Its contents match the uploaded package
(`npm run zip:firefox` creates `lumen-proxy-firefox.zip` from that folder).

## What the build does

`npm run build:firefox` runs:

1. `node scripts/icons.mjs` — renders `assets/icon.svg` to PNG icons with `@resvg/resvg-js`.
2. `vite build --mode firefox` — compiles TypeScript and Svelte from `src/` and minifies with esbuild.
   The Vite config (`vite.config.ts`) also writes `manifest.json` (merged from `manifest/base.json` and
   `manifest/firefox.json`) and `LICENSE.txt` (licenses of bundled packages).

No code is downloaded at runtime and nothing is generated by remote services. All dependencies come from
`package-lock.json`.

## Source map

| Built file | Source |
|---|---|
| `background.js` | `src/background/index.ts`, `src/platform/firefox.ts`, `src/shared/` |
| `popup.html`, `assets/popup-*.js` | `src/popup/` |
| `options.html`, `assets/options-*.js` | `src/options/` |
| `assets/firefox-*.js` | shared chunk: `src/platform/firefox.ts`, `src/shared/`, `acorn` (PAC syntax check) |
| `assets/Segmented-*.js` | shared chunk: Svelte runtime and `src/ui/` components |

## Note on the linter warning

`addons-linter` reports one `UNSAFE_VAR_ASSIGNMENT` (innerHTML) in the Svelte runtime. Svelte uses it to create
DOM from templates compiled at build time; no user or remote data reaches it, and the source does not use `{@html}`.
